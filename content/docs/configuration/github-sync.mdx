---
title: GitHub Sync
description: Share port-forward configurations across a team through a GitHub repository.
---

GitHub sync pulls your team's port-forward configs from a shared repository.

## Setup

### Create a configuration repository

Create a GitHub repository to hold your team's port-forward configurations:

```bash
mkdir kftray-configs
cd kftray-configs
git init

# Create configuration files
cat > production.json <<EOF
[
  {
    "service": "api-gateway",
    "namespace": "production",
    "local_port": 8080,
    "remote_port": 80,
    "context": "prod-cluster",
    "alias": "Production API"
  },
  {
    "service": "postgres",
    "namespace": "databases",
    "local_port": 5432,
    "remote_port": 5432,
    "context": "prod-cluster",
    "alias": "Production Database"
  }
]
EOF

git add production.json
git commit -m "Add production configurations"
git remote add origin git@github.com:your-org/kftray-configs.git
git push -u origin main
```

### Repository structure

<Files>
<Folder name="kftray-configs" defaultOpen>
<File name="production.json" />
<File name="staging.json" />
<File name="development.json" />
<File name="README.md" />
</Folder>
</Files>

Each JSON file holds an array of [configuration objects](/docs/configuration). You can organize files by environment, team or service group.

### Configure sync

<Tabs items={['Desktop', 'Terminal']}>
<Tab value="Desktop">

<Steps>
<Step>
Open the kftray desktop interface.
</Step>
<Step>
Go to Settings → GitHub Sync.
</Step>
<Step>
Enter the repository URL: `https://github.com/your-org/kftray-configs`
</Step>
<Step>
Enter the branch name: `main`
</Step>
<Step>
Enter a personal access token. See [Authentication](#authentication) for the required permissions.
</Step>
<Step>
Click "Enable Sync".
</Step>
</Steps>

kftray fetches the configs as soon as you turn on sync.

</Tab>
<Tab value="Terminal">

Pass the GitHub repository URL and the config file path when you launch kftui:

```bash
kftui --github-url https://github.com/your-org/kftray-configs --configs-path env/production.json
```

Add `--save` to keep the imported configurations in the local database:

```bash
kftui --github-url https://github.com/your-org/kftray-configs --configs-path env/production.json --save
```

For private repositories, set the `GITHUB_TOKEN` environment variable before you launch.

</Tab>
</Tabs>

## Authentication

GitHub sync needs a personal access token with the `repo` scope for private repositories or the `public_repo` scope for public ones.

Create a token at https://github.com/settings/tokens:

<Steps>
<Step>
Click "Generate new token (classic)".
</Step>
<Step>
Name it "kftray sync".
</Step>
<Step>
Set an expiration that fits your security policy.
</Step>
<Step>
Select the `repo` scope, or `public_repo` for public repositories only.
</Step>
<Step>
Click "Generate token".
</Step>
<Step>
Copy the token right away, because GitHub won't show it again.
</Step>
</Steps>

<Callout type="error" title="Token security">
A personal access token grants access to every repository in its scope. Store tokens securely and rotate them regularly. Never commit tokens to version control or share them in chat.
</Callout>

## Sync behavior

### Periodic checks

kftray checks the repository every 5 minutes. When it finds changes, kftray:

<Steps>
<Step>
Adds new configs to your local database.
</Step>
<Step>
Updates existing configs, matching them by service, namespace and context.
</Step>
<Step>
Removes configs that the repository no longer contains.
</Step>
</Steps>

### Conflict resolution

The repository always wins. If you change a synced configuration locally, the next sync overwrites it with the repository version.

To keep local changes:

<Steps>
<Step>
Disable GitHub sync.
</Step>
<Step>
Export your local configurations.
</Step>
<Step>
Merge your changes into the repository.
</Step>
<Step>
Push to GitHub.
</Step>
<Step>
Enable sync again.
</Step>
</Steps>

### Manual trigger

To fetch the latest configs before the next scheduled check:

<Steps>
<Step>
Go to Settings → GitHub Sync.
</Step>
<Step>
Click "Sync Now".
</Step>
</Steps>
