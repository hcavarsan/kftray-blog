---
title: HTTP Logging
description: Record HTTP requests and responses from port forwards in a format compatible with the VS Code REST Client.
---

HTTP logging records the requests and responses that pass through your port forwards, so you can debug API calls.

## Enabling HTTP logging

<Tabs items={['Desktop', 'Terminal']}>
<Tab value="Desktop">

<Steps>
<Step>
Right-click the port forward in the desktop interface.
</Step>
<Step>
Select "Configure HTTP Logging".
</Step>
<Step>
Toggle "Enable HTTP Logging".
</Step>
<Step>
Click "Save".
</Step>
</Steps>

</Tab>
<Tab value="Terminal">

Press `l` to toggle HTTP logging on the selected configuration, or set `"http_logs_enabled": true` in your JSON config.

Press `L` to set log retention (1 to 365 days) and maximum log size (1 to 1000 MB).

</Tab>
</Tabs>

Logging starts right away for new connections. Existing connections stay unlogged until they reconnect.

## Log file location

Logs go to `~/.kftray/http_logs/`, with one file per port forward:

<Files>
<Folder name="~/.kftray/http_logs" defaultOpen>
<File name="api-gateway-8080.log" />
<File name="auth-service-8001.log" />
<File name="user-service-8002.log" />
</Folder>
</Files>

File names follow the pattern `{alias-or-service}-{local-port}.log`.

## Log format

```
[2026-02-09T14:32:15.123Z] trace_id=a1b2c3d4 method=POST path=/api/users status=201 duration=45ms

REQUEST:
POST /api/users HTTP/1.1
Host: localhost:8080
Content-Type: application/json
Authorization: Bearer eyJhbGc...
Content-Length: 87

{"email":"user@example.com","name":"Jane Doe","role":"admin"}

RESPONSE:
HTTP/1.1 201 Created
Content-Type: application/json
X-Request-ID: a1b2c3d4
Content-Length: 156

{"id":"usr_123","email":"user@example.com","name":"Jane Doe","role":"admin","created_at":"2026-02-09T14:32:15Z"}

---
```

Each log entry includes:

| Field | Detail |
|---|---|
| Timestamp | Millisecond precision |
| Trace ID | Links related requests |
| HTTP method, path, status code | Identifies the request |
| Request duration | How long the request took |
| Full request headers and body | The complete request |
| Full response headers and body | The complete response |

## Log management

### Viewing logs in kftui

Press `V` to open the log viewer for the selected configuration. In the detail view, press `r` to replay an HTTP request and retest an endpoint. Press `o` to open the logs in your default external editor.

### Cleanup

Delete old logs manually:

```bash
rm ~/.kftray/http_logs/*.log
```

<Callout type="error" title="Sensitive data in logs">
HTTP logs capture full request and response bodies, including authentication tokens, API keys and personal data. Delete the logs when you finish debugging.
</Callout>
