title: Terminal Interface

The kftui terminal interface manages Kubernetes port forwards from the keyboard. It uses few resources and works over SSH. For command-line flags, non-interactive mode and scripting, see the [CLI](/docs/interfaces/cli) page.

![kftui terminal interface](/img/kftui2025.png)

## Interface layout

kftui has four panels:

- Stopped Configs: configurations not currently forwarding
- Running Configs: active port forwards with live status
- Details: full configuration details for the selected entry (service, namespace, ports, HTTP logs path)
- Logs: application log output

The status column uses these indicators:

| Indicator | Meaning |
|-----------|---------|
| Green | Active connection |
| Red | Stopped |
| Yellow | Connecting or error |

## Keyboard shortcuts

| Shortcut | Action |
|----------|--------|
| `↑` `↓` | Navigate configurations |
| `←` `→` | Navigate table columns |
| `Space` | Select or deselect a config |
| `a` | Select all configurations |
| `f` | Start or stop forwards for selected configs |
| `i` | Import configurations from JSON |
| `e` | Export configurations to JSON |
| `d` | Delete selected configurations |
| `s` | Open settings |
| `l` | Turn HTTP logging on or off for selected configs |
| `L` | Set HTTP log retention and maximum size |
| `V` | View HTTP logs for selected configs |
| `o` | Open HTTP logs in an external editor |
| `v` | Group by and filter configurations ([details](/docs/configuration/tags-and-views#terminal-kftui)) |
| `t` | Edit tags of the selected configuration |
| `r` | Replay an HTTP request from the log detail view |
| `h` | Show help |
| `q` | Quit the app |
| `Tab` | Switch interface sections |
| `Enter` | Confirm action |
| `Esc` | Cancel action |
| `Ctrl+C` | Exit |

## Configuration management

<Tabs items={['Import', 'Export', 'Delete']}>
<Tab value="Import">

Press `i` to open the import dialog.

File browser navigation:
```
↑ ↓     Navigate files/directories
Enter   Select file or enter directory
..      Go up one directory
Esc     Cancel import
```

To import:

<Steps>
<Step>
Navigate to the JSON configuration file.
</Step>
<Step>
Press `Enter` to select it.
</Step>
<Step>
Review the configurations to import.
</Step>
<Step>
Press `Enter` to confirm.
</Step>
</Steps>

The JSON format:
```json
[
  {
    "service": "api-gateway",
    "namespace": "development",
    "local_port": 8080,
    "remote_port": 80,
    "protocol": "tcp",
    "alias": "gateway"
  }
]
```

Validation errors appear immediately, with details about what to fix.

## Port forward management

To start a forward:

<Steps>
<Step>
Navigate to the configuration with `↑` `↓`.
</Step>
<Step>
Press `Space` to select it.
</Step>
<Step>
Press `f` to toggle the forward.
</Step>
</Steps>

The status changes from `○ Stopped` to `⚠ Connecting` to `● Running`.

To start several forwards at once:

<Steps>
<Step>
Press `Ctrl+A` to select all.
</Step>
<Step>
Press `f` to start all selected forwards.
</Step>
</Steps>

To stop forwards, use the same selection and toggle pattern. Navigate to the running configurations, select them with `Space` and press `f`.

Failed forwards show the `⚠ Error` status. Navigate to the configuration and press `Enter` to view the error details.

## Auto import

To run it:

<Steps>
<Step>
Press `Tab` to open the menu.
</Step>
<Step>
Navigate to "Auto Import" with `↑` `↓`.
</Step>
<Step>
Press `Enter` to select it.
</Step>
<Step>
Choose the kubeconfig and context.
</Step>
<Step>
Select the target namespace.
</Step>
<Step>
Review the discovered services with the `kftray.app/enabled` annotation.
</Step>
<Step>
Select the services to import with `Space`.
</Step>
<Step>
Press `Enter` to confirm the import.
</Step>
</Steps>

See [Auto Import](/docs/configuration/auto-import) for the annotation format and service discovery details.

Imported configurations merge with existing ones, so running auto import several times creates no duplicates.
