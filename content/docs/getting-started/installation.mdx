Pick the install method that matches your platform, then continue with the [Quick Start](/docs/getting-started/quick-start).

## Desktop Interface (kftray)

<Tabs items={['macOS', 'Linux', 'Windows']}>
<Tab value="macOS">

Install with Homebrew (recommended):

```bash
brew tap hcavarsan/kftray
brew install --cask kftray
```

Or download `kftray_universal.dmg` from the [latest release](https://github.com/hcavarsan/kftray/releases/latest). The universal binary runs on both Intel and Apple Silicon.

</Tab>
<Tab value="Linux">

On Debian, Ubuntu, Fedora and openSUSE, you can install the `kftray` package from the [package repositories](#linux-packages) below.

To install with Homebrew:

```bash
brew tap hcavarsan/kftray
brew install kftray-linux
```

Or download the AppImage from the [latest release](https://github.com/hcavarsan/kftray/releases/latest):

- `kftray_amd64.AppImage` for x86_64 systems
- `kftray_aarch64.AppImage` for ARM64 systems

Make it executable, then run it:

```bash
chmod +x kftray_amd64.AppImage
./kftray_amd64.AppImage
```

<Callout type="warn" title="GNOME Users">
The system tray icon needs AppIndicator support. Install the [AppIndicator extension](https://extensions.gnome.org/extension/615/appindicator-support/) so the icon appears. KDE, XFCE and i3 include tray support by default.
</Callout>

</Tab>
<Tab value="Windows">

Download the installer from the [latest release](https://github.com/hcavarsan/kftray/releases/latest):

- `kftray_x64-setup.exe` for standard x86_64 systems
- `kftray_arm64-setup.exe` for ARM64 devices, such as Surface Pro X

The installer sets up `PATH` and creates Start Menu entries automatically.

</Tab>
</Tabs>

## Terminal Interface (kftui)

<Tabs items={['Homebrew', 'Cargo', 'Linux Packages', 'Installer Script', 'Windows']}>
<Tab value="Homebrew">

```bash
brew tap hcavarsan/kftray
brew install kftui
```

</Tab>
<Tab value="Cargo">

```bash
cargo install kftui
```

This needs a working Rust toolchain. If you don't have one, see [rustup.rs](https://rustup.rs).

</Tab>
<Tab value="Linux Packages">

Add the [package repository](#linux-packages) for your distribution, then run:

```bash
sudo apt install kftui     # Debian and Ubuntu
sudo dnf install kftui     # Fedora
sudo zypper install kftui  # openSUSE
```

</Tab>
<Tab value="Installer Script">

```bash
bash <(curl -s https://raw.githubusercontent.com/hcavarsan/kftray/main/hacks/kftui_installer.sh)
```

Or with `wget`:

```bash
bash <(wget -qO- https://raw.githubusercontent.com/hcavarsan/kftray/main/hacks/kftui_installer.sh)
```

The script installs `kftui` to `/usr/local/bin/`, which needs `sudo` for the system-wide install.

</Tab>
<Tab value="Windows">

Run this in PowerShell:

```powershell
Invoke-Expression ((New-Object System.Net.WebClient).DownloadString('https://raw.githubusercontent.com/hcavarsan/kftray/main/hacks/kftui_installer.ps1'))
```

</Tab>
</Tabs>

### Manual Binary Downloads

If your network blocks the installer scripts, download the binaries from the [latest release](https://github.com/hcavarsan/kftray/releases/latest):

| Platform | Desktop | Terminal |
|---|---|---|
| macOS (Universal) | `kftray_universal.dmg` | `kftui_macos_universal` |
| Linux x86_64 | `kftray_amd64.AppImage` | `kftui_amd64` |
| Linux ARM64 | `kftray_aarch64.AppImage` | `kftui_arm64` |
| Windows x64 | `kftray_x64-setup.exe` | `kftui_x86_64.exe` |
| Windows ARM64 | `kftray_arm64-setup.exe` | None |

## Linux Packages

Each release publishes `kftray` and `kftui` packages for Debian, Ubuntu, Fedora and openSUSE through the [openSUSE Build Service](https://build.opensuse.org/project/show/home:hencavarsan:kftray). Add the repository once and install either package with your package manager. Updates arrive with regular system upgrades.

The commands below install `kftui`. Replace it with `kftray` for the desktop app.

<Tabs items={['Debian / Ubuntu', 'Fedora', 'openSUSE']}>
<Tab value="Debian / Ubuntu">

Replace `Debian_12` with `Debian_13`, `Ubuntu_22.04`, `Ubuntu_24.04` or `Ubuntu_26.04` as needed:

```bash
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://download.opensuse.org/repositories/home:/hencavarsan:/kftray/Debian_12/Release.key | sudo gpg --dearmor -o /etc/apt/keyrings/kftray.gpg
echo "deb [signed-by=/etc/apt/keyrings/kftray.gpg] https://download.opensuse.org/repositories/home:/hencavarsan:/kftray/Debian_12/ /" | sudo tee /etc/apt/sources.list.d/kftray.list
sudo apt update
sudo apt install kftui
```

</Tab>
<Tab value="Fedora">

Replace `Fedora_44` with `Fedora_43` if needed:

```bash
sudo dnf config-manager addrepo --from-repofile=https://download.opensuse.org/repositories/home:/hencavarsan:/kftray/Fedora_44/home:hencavarsan:kftray.repo
sudo dnf install kftui
```

</Tab>
<Tab value="openSUSE">

Replace `openSUSE_Tumbleweed` with `openSUSE_Leap_16.0` for Leap:

```bash
sudo zypper addrepo https://download.opensuse.org/repositories/home:/hencavarsan:/kftray/openSUSE_Tumbleweed/home:hencavarsan:kftray.repo
sudo zypper --gpg-auto-import-keys refresh
sudo zypper install kftui
```

</Tab>
</Tabs>

The packages use the signing key for `home:hencavarsan:kftray`. The `.repo` files reference that key, and the apt source pins it with `signed-by`.

The `kftray` package ships the AppImage and depends on `fuse3`. The `kftui` package depends on `libdbus-1`.

## Verifying the Installation

<Tabs items={['Desktop', 'Terminal']}>
<Tab value="Desktop">

Launch kftray from your applications menu. The main window opens and a system tray icon (a small Kubernetes logo) appears. The window hides when it loses focus, so click the icon to open it again.

</Tab>
<Tab value="Terminal">

```bash
kftui
```

You should see a text-based interface with an empty configuration list and keyboard shortcuts at the bottom. Press `Ctrl+C` to exit.

</Tab>
</Tabs>

## Configuration Storage

Both interfaces store data in `~/.kftray/`:

| File | Purpose |
|---|---|
| `kftray.db` | SQLite database with all configurations and state |
| `app.log` | Application logs |
| `http_logs/` | HTTP traffic captures (when enabled) |

Both interfaces share this directory, so configurations created in one appear instantly in the other.
