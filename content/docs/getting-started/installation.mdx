Pick the install method that matches your platform, then continue with the [Quick Start](/docs/getting-started/quick-start).

## Desktop Interface (kftray)

<Tabs items={['macOS', 'Linux', 'Windows']}>
<Tab value="macOS">

Install with Homebrew (recommended):

```bash
brew tap hcavarsan/kftray
brew install --cask kftray
```

Or download the versioned `.dmg` from the [downloads page](/downloads). The universal binary runs on Intel and Apple Silicon.

</Tab>
<Tab value="Linux">

On Debian, Ubuntu, Fedora, openSUSE and Arch Linux, install the `kftray` package from the [package repositories](#linux-packages) below.

To install with Homebrew:

```bash
brew tap hcavarsan/kftray
brew install kftray-linux
```

Homebrew prints caveats with instructions for making the app available in your applications menu.

Or download an AppImage from the [downloads page](/downloads). Choose `amd64` for x86_64 or `aarch64` for ARM64.
For Ubuntu 24.04 and newer distributions, use the `newer-glibc` build.

Make the downloaded file executable and run it, replacing the filename with the one you downloaded:

```bash
chmod +x ./kftray_0.30.3_amd64.AppImage
./kftray_0.30.3_amd64.AppImage
```

kftray uses StatusNotifierItem (SNI) for the Linux tray. KDE, Cinnamon, MATE, XFCE, LXQt and Unity provide an SNI host.
On GNOME, install the [AppIndicator and KStatusNotifierItem Support extension](https://extensions.gnome.org/extension/615/appindicator-support/).
Without an SNI host, kftray opens as a regular window and switches to the tray when a host becomes available.
See [app mode](/docs/interfaces/desktop#app-mode) for window behavior.

AppImage updates restart from the updated file. If an older version repeats the update prompt, quit it completely and reopen the AppImage once.

</Tab>
<Tab value="Windows">

Download the Windows installer from the [downloads page](/downloads). Choose `x64`, `arm64` or `x86` to match your system.

</Tab>
</Tabs>

## Terminal Interface (kftui)

<Tabs items={['Homebrew', 'Cargo', 'Linux Packages', 'Installer Script', 'Windows']}>
<Tab value="Homebrew">

```bash
brew tap hcavarsan/kftray
brew install kftui
```

</Tab>
<Tab value="Cargo">

```bash
cargo install kftui
```

This needs a working Rust toolchain. If you don't have one, see [rustup.rs](https://rustup.rs).

</Tab>
<Tab value="Linux Packages">

Add the [package repository](#linux-packages) for your distribution. That section includes the install command for each package manager.

</Tab>
<Tab value="Installer Script">

The installer needs `curl` or `wget`. On Linux, macOS or WSL, run it from Bash:

```bash
bash <(curl -s https://raw.githubusercontent.com/hcavarsan/kftray/main/hacks/kftui_installer.sh)
```

Or with `wget`:

```bash
bash <(wget -qO- https://raw.githubusercontent.com/hcavarsan/kftray/main/hacks/kftui_installer.sh)
```

From Fish, pipe the script to Bash:

```fish
curl -s https://raw.githubusercontent.com/hcavarsan/kftray/main/hacks/kftui_installer.sh | bash
```

Or use `wget`:

```fish
wget -qO- https://raw.githubusercontent.com/hcavarsan/kftray/main/hacks/kftui_installer.sh | bash
```

The script installs `kftui` to `/usr/local/bin/`, which needs `sudo` for the system-wide install.

</Tab>
<Tab value="Windows">

Run this in PowerShell:

```powershell
Invoke-Expression ((New-Object System.Net.WebClient).DownloadString('https://raw.githubusercontent.com/hcavarsan/kftray/main/hacks/kftui_installer.ps1'))
```

</Tab>
</Tabs>

### Manual Binary Downloads

Use the [downloads page](/downloads) to select an app, operating system and CPU architecture.
The [release page](https://github.com/hcavarsan/kftray/releases/latest) also lists the downloadable files.

Desktop filenames include the release version. Terminal binaries use these names:

| Platform | Terminal binary |
|---|---|
| macOS (Universal) | `kftui_macos_universal` |
| Linux x86_64 | `kftui_linux_amd64` |
| Linux ARM64 | `kftui_linux_arm64` |
| Windows x64 | `kftui_windows_x86_64.exe` |
| Windows x86 | `kftui_windows_x86.exe` |
| Windows ARM64 | `kftui_windows_arm64.exe` |

## Linux Packages

Each release publishes `kftray` and `kftui` packages for Debian, Ubuntu, Fedora, openSUSE and Arch Linux through the [openSUSE Build Service](https://build.opensuse.org/project/show/home:hencavarsan:kftray). Add the repository once and install either package with your package manager. Updates arrive with regular system upgrades.

The commands below install `kftui`. Replace it with `kftray` for the desktop app.

<Tabs items={['Debian / Ubuntu', 'Fedora', 'openSUSE', 'Arch Linux']}>
<Tab value="Debian / Ubuntu">

Replace `Debian_12` with `Debian_13`, `Ubuntu_22.04`, `Ubuntu_24.04` or `Ubuntu_26.04` as needed:

```bash
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://download.opensuse.org/repositories/home:/hencavarsan:/kftray/Debian_12/Release.key | sudo gpg --dearmor -o /etc/apt/keyrings/kftray.gpg
echo "deb [signed-by=/etc/apt/keyrings/kftray.gpg] https://download.opensuse.org/repositories/home:/hencavarsan:/kftray/Debian_12/ /" | sudo tee /etc/apt/sources.list.d/kftray.list
sudo apt update
sudo apt install kftui
```

</Tab>
<Tab value="Fedora">

Replace `Fedora_44` with `Fedora_43` if needed:

```bash
sudo dnf config-manager addrepo --from-repofile=https://download.opensuse.org/repositories/home:/hencavarsan:/kftray/Fedora_44/home:hencavarsan:kftray.repo
sudo dnf install kftui
```

</Tab>
<Tab value="openSUSE">

Replace `openSUSE_Tumbleweed` with `openSUSE_Leap_16.0` for Leap:

```bash
sudo zypper addrepo https://download.opensuse.org/repositories/home:/hencavarsan:/kftray/openSUSE_Tumbleweed/home:hencavarsan:kftray.repo
sudo zypper --gpg-auto-import-keys refresh
sudo zypper install kftui
```

</Tab>
<Tab value="Arch Linux">

The Arch repository supports x86_64:

```bash
curl -fsSL https://download.opensuse.org/repositories/home:/hencavarsan:/kftray/Arch/x86_64/home_hencavarsan_kftray_Arch.key -o /tmp/kftray.key
sudo pacman-key --add /tmp/kftray.key
sudo pacman-key --lsign-key "$(gpg --with-colons --show-keys /tmp/kftray.key | awk -F: '$1 == "fpr" { print $10; exit }')"
printf '\n[home_hencavarsan_kftray_Arch]\nServer = https://download.opensuse.org/repositories/home:/hencavarsan:/kftray/Arch/$arch\n' | sudo tee -a /etc/pacman.conf
sudo pacman -Syu kftui
```

</Tab>
</Tabs>

The packages use the signing key for `home:hencavarsan:kftray`. The `.repo` files reference it, apt pins it with `signed-by` and pacman trusts it after `pacman-key --lsign-key`.

The `kftray` package ships the AppImage and depends on `fuse3`. The `kftui` package depends on `libdbus-1`.

## Verifying the Installation

<Tabs items={['Desktop', 'Terminal']}>
<Tab value="Desktop">

Launch kftray from your applications menu or open the AppImage. Check [app mode](/docs/interfaces/desktop#app-mode) if the tray icon is unavailable or you prefer a regular window.

</Tab>
<Tab value="Terminal">

```bash
kftui
```

Restart your terminal after installation and run `kftui`. The configuration list and keyboard shortcuts appear. Press `Ctrl+C` to exit.

</Tab>
</Tabs>
