---
title: Quick Start
description: Create your first port-forward configuration, start it and verify the connection.
---

Forward a Kubernetes web service to `localhost:8080` and check the connection with `curl`.

## Prerequisites

- kftray or kftui [installed](/docs/getting-started/installation)
- A running Kubernetes cluster you can reach through `kubeconfig`
- A running service. The examples use a web service on port `80`.

Check your cluster access first:

```bash
kubectl get services -n default
```

## Step 1: Create a Configuration

<Tabs items={['Desktop', 'Terminal']}>
<Tab value="Desktop">

<Steps>
<Step>
Launch kftray. The main window opens on start. If it is hidden, click the system tray icon to open it again.
</Step>
<Step>
Click the `+` button or press `Ctrl+N` / `Cmd+N`.
</Step>
<Step>
Fill in the configuration form:

| Field | Value |
|---|---|
| Service | `my-service` |
| Namespace | `default` |
| Local Port | `8080` |
| Remote Port | `80` |
| Protocol | `tcp` |
| Alias | `web` |
</Step>
<Step>
Click "Save".
</Step>
</Steps>

</Tab>
<Tab value="Terminal">

Create a JSON configuration file:

```json
[
  {
    "service": "my-service",
    "namespace": "default",
    "local_port": 8080,
    "remote_port": 80,
    "context": "my-cluster",
    "workload_type": "service",
    "protocol": "tcp",
    "alias": "web"
  }
]
```

Save it as `config.json`, then import it in kftui:

<Steps>
<Step>
Launch `kftui`.
</Step>
<Step>
Press `i` to open the import dialog.
</Step>
<Step>
Navigate to your `config.json` file and press `Enter`.
</Step>
</Steps>

</Tab>
</Tabs>

## Step 2: Start the Port Forward

<Tabs items={['Desktop', 'Terminal']}>
<Tab value="Desktop">

Toggle the switch next to your `web` config, or click "Start All" to start every forward.

A green status indicator means the connection is active.

</Tab>
<Tab value="Terminal">

<Steps>
<Step>
Use the arrow keys to move to the `web` config.
</Step>
<Step>
Press `Space` to select it.
</Step>
<Step>
Press `f` to start forwarding.
</Step>
</Steps>

The status column changes to "Running".

</Tab>
</Tabs>

## Step 3: Verify the Connection

Test that traffic flows through the forward:

```bash
curl http://localhost:8080
```

You should see the response from your Kubernetes service. For database services, point your client at `localhost:LOCAL_PORT` as usual.

## Step 4: Test Automatic Reconnection

Restart the target pod to see automatic reconnection:

```bash
kubectl rollout restart deployment/my-service -n default
```

kftray briefly shows a reconnection attempt before the status returns to green (running).
